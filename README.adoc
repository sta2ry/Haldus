== 介绍

Haldus（御夫座柱一星）是 **sta2ry 星宇星群**中的用户基础服务。

在 sta2ry 星宇星群中，每个库都以一个星座或星座中的恒星命名——Haldus 取自御夫座（Auriga），御夫即驭者，寓意**将用户服务好**。

作为通用的用户基础微服务，Haldus 不绑定任何特定业务领域（如交易所、支付等），任何需要用户体系的业务均可直接复用：

* 账号（Account）与用户信息（UserInfo）
* 认证（Auth）与第三方授权（OAuth）
* 密码管理与 Token 令牌
* 用户联系方式（Contact）
* 第三方平台绑定（UserLinkBind）
* 注册来源渠道（UserSource）
* 推荐码体系：建立推荐码、绑定推荐人与合作商

基础但完备，通用且可扩展。

== 运行

启动应用：

[source,bash]
----
./gradlew :haldus-vert:run
----

应用默认监听 8888 端口。

== 构建

编译打包：

[source,bash]
----
./gradlew clean assemble
----

运行测试：

[source,bash]
----
./gradlew clean test
----
